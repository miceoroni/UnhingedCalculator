## Run Locally

Clone the project

```bash
  git clone https://github.com/miceoroni/UnhingedCalculator.git
```

Go to the project directory

```bash
  cd UnhingedCalculator
```

Build using godot

Linux example:
```bash
godot --headless --export-debug "Linux" build\unhinged_calc.x86_64
```
